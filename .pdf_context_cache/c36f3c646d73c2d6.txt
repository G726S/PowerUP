# Classical Machine Learning (Low Dimension)

## 1. Introduction to Low-Dimensional Machine Learning

* **Definition of Classical ML:** Methods that operate and perform very well in low-dimensional spaces.
* **Why Low Dimension:**
  * Many datasets naturally exist in low dimensions, or can be transformed into low dimensions.
  * Low-dimensional data is significantly easier and faster to process and interpret.
  * Machine learning is conceptualized as interpreting maps; smaller dimensions equate to faster and simpler interpretation.
* **The Two Fundamental Tasks of Machine Learning:**
  1. **Classification / Decision:** The machine learns thresholds or decision boundaries to split data into discrete classes.
  2. **Regression:** The machine learns the parameters of a continuous functional model to best fit the data.
  * *Contrast with non-ML approaches:* 
    * **Decision-based Logic:** Human experts write down explicit rules and logic.
    * **Physics-based Modelling:** Human experts write an analytical model based on physical/chemical laws, and a small number of parameters are fitted to match data.

## 2. Linear Regression

* **Core Goal:** Model a linear mapping between input features (independent variables $x$) and an output target (dependent variable $y$).
* **Simple Linear Model:**
$$\hat{y} = mx + c$$
  * Where $\hat{y}$ is the model prediction, $x$ is the input feature, $m$ is the slope (weight), and $c$ is the intercept (bias).
* **Error / Residual Definition:**
$$\epsilon = \hat{y} - y$$
  * $\hat{y}$: Prediction (model estimate)
  * $y$: Ground-truth (actual output)
  * $\epsilon$: Error / residual

### Ordinary Least Squares (OLS) Solution
* **Cost Function:** Minimize the sum of squared residuals:
$$\min_{W} \|AW - B\|^2 = \min_{W} J$$
* **Matrix Formulation:**
  * Target vector: 
  $$B = \begin{bmatrix} y_1 \\ \vdots \\ y_N \end{bmatrix}$$
  * Design matrix (for simple regression): 
  $$A = \begin{bmatrix} x_1 & 1 \\ \vdots & \vdots \\ x_N & 1 \end{bmatrix}$$
  * Parameter vector: 
  $$W = \begin{bmatrix} m \\ c \end{bmatrix}$$
* **Derivation & Normal Equation:**
  * Taking the derivative of the cost function with respect to $W$ and setting it to zero:
  $$\frac{dJ}{dW} = 2A^T(AW - B) = 0 \implies A^TAW = A^TB$$
* **Closed-Form OLS Solution:**
$$W = (A^TA)^{-1}A^TB$$
  * Where $(A^TA)^{-1}A^T$ is the Moore-Penrose pseudo-inverse.

### Relationship Between Sample Size ($N$) and Parameters ($P=2$):
* **$N > 2$ (More samples than parameters):** The system is overdetermined and has a unique solution. Highly robust to noise.
* **$N = 2$ (Equal samples and parameters):** The solution is unique and fits the data points (and any noise) exactly.
* **$N < 2$ (Fewer samples than parameters):** The problem is ill-posed, underdetermined/overparameterized, and will severely overfit.

### Multiple Variable Linear Regression
* Extends the input space to multiple features ($x_1, x_2, x_3$):
$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3$$
* Design matrix $A$ expands to include columns for each feature alongside a column of ones for the intercept ($\beta_0$). The closed-form solution $W = (A^TA)^{-1}A^TB$ remains identical.

### Assumptions of Linear Regression
1. **Linearity:** A linear relationship exists between input and output variables (correlation is required, causation is not).
2. **Independence:** Residuals (errors) are independent of each other (critical for time-series data).
3. **Homoscedasticity:** Residuals have constant variance across all levels of $x$.
4. **Normality:** Residuals follow a normal distribution centered at zero.

### Limitations of Linear Regression
1. Cannot capture non-linear (complex) relationships.
2. Highly sensitive to outliers.
3. Vulnerable to **Simpson's Paradox** (where a trend observed in subgroups reverses or disappears when groups are combined).

## 3. Correlation Metrics

* **Pearson’s Correlation Coefficient ($r$):**
  * Assesses **linear** relationships between variables.
  * Formula:
  $$r_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$
* **Spearman’s Correlation Coefficient:**
  * Assesses **monotonic** relationships (whether linear or non-linear).
  * Calculated as the Pearson correlation applied between the *rank values* of the variables rather than raw values.

## 4. Alternative Parameter Optimization Methods

* **Grid Search:**
  * Discretizes the parameter space into a grid, computes the Mean Squared Error (MSE) for every combination of parameters, and picks the combination yielding the minimum error.
  * Limited by resolution and computational cost in high dimensions.
* **Gradient Descent:**
  * Iteratively updates parameters in the opposite direction of the gradient of the cost function.
  * **Critical Requirement — Data Normalization:** If input features and target variables operate on vastly different scales (e.g., $x \sim 30$, $y \sim 0.05$), gradients distort and fail to point toward the true steepest descent, preventing convergence. Normalizing data (zero mean, unit variance) solves this.

## 5. Non-Linear Regression & Polynomial Regression

* When relationships are non-linear, approaches include:
  1. Applying mathematical transformations to the data (e.g., $\log(y)$) to linearize the relationship.
  2. Adopting a more complex model class, such as **Polynomial Regression**.
* **Polynomial Regression Models:**
  * 2nd Order: $\hat{y} = b_2 x^2 + b_1 x + b_0$
  * 3rd Order: $\hat{y} = b_3 x^3 + b_2 x^2 + b_1 x + b_0$
  * General $N$-th Order: $\hat{y} = \sum_{i=0}^{N} b_i x^i$
* **Matrix Formulation:** Despite non-linearity in $x$, polynomial regression is *linear in its parameters* ($b_i$), meaning it can still be solved analytically using the standard OLS equation $W = (A^TA)^{-1}A^TB$ by constructing design matrix columns as powers of $x$ (e.g., $[1, x, x^2, \dots, x^N]$).

## 6. Experimental Design, Overfitting, and Validation

* **Overfitting:** Occurs when a model (such as a high-order polynomial, e.g., 9th order) captures noise rather than the underlying pattern, resulting in low training error but high generalization error on unseen data.
* **Data Splitting Best Practice:**
  * **Training Set:** Used to fit model parameters ($W$).
  * **Validation Set:** Used to tune **hyperparameters** (such as polynomial degree $N$ or $K$ in KNN).
  * **Testing Set:** Kept strictly secret until the final step to evaluate unbiased model generalization performance.
* **K-Fold Cross-Validation:**
  * The dataset is split into $K$ folds (e.g., 8 folds).
  * The model is trained and validated $K$ times, using a different fold as the validation set in each iteration and the remaining $K-1$ folds for training.
  * Performance metrics are averaged across all $K$ runs to select optimal hyperparameters reliably, especially under data scarcity.
  * **Extreme Variant:** *Leave-One-Out Cross-Validation (LOOCV)*, where $K = N$.

## 7. Classification and Clustering

* **Core Objective:** Assign data points to discrete categories or find boundaries separating groups.
* **Supervised vs. Unsupervised Strategies:**
  * Unsupervised clustering finds natural groupings without labels.
  * Supervised classification learns boundaries using labeled data.

### K-Nearest Neighbors (KNN)
* **How it works (Classification):**
  1. Normalize input features (crucial so distance metrics are not dominated by larger-scale features).
  2. Store all training data (KNN is a *non-parametric*, lazy-learning algorithm that memorizes data rather than fitting explicit parameters).
  3. Compute distances (Euclidean or Cosine distance) from a query point to every point in the training dataset.
  4. Find the $K$ closest training points.
  5. Assign the class label via a majority vote among the $K$ neighbors.
* **Hyperparameter $K$ Selection:** Evaluated across a range of values using the validation dataset to maximize accuracy.
* **KNN for Regression:** Predicts a continuous output value for a query point by taking the average (or weighted average) of the target values of its $K$ nearest neighbors.
* **Advantages:** Highly interpretable; no parameter estimation phase required; easy to incorporate new data dynamically.
* **Limitations:** Computationally expensive during inference (must scan all training points); highly sensitive to outliers (when $K$ is small); suffers severely from the *Curse of Dimensionality*.

### Decision Trees
* **How it works:** Recursively splits the feature space using axis-aligned thresholds (rules like "If Income $< \$35,000$ or $\text{LVR} > 0.8$, then Deny"). Visualized as a hierarchical flowchart structure.
* **Assumptions:** Data features can be thresholded to effectively separate classes.
* **Advantages:** Highly interpretable/explainable; requires minimal data preprocessing (no normalization needed); naturally captures non-linear, piecewise decision boundaries.
* **Limitations:** Prone to overfitting (mitigated via pruning); unstable to small changes in training data; sensitive to class imbalance; computationally expensive to train optimally on large datasets.
* **Random Forest:** An ensemble method combining multiple decision trees trained on bootstrapped subsets of the data, using majority voting/averaging to reduce overfitting and variance.

## 8. Evaluation Metrics for Classification

### Confusion Matrix Structure
* Compares **Ground-Truth** rows against **Predicted** columns for multi-class classification (e.g., *Cold, Warm, Hot*).
* **Correct Predictions:** Form the diagonal of the matrix.
* **Incorrect Predictions (Errors):** Populate the off-diagonal cells, indicating specific types of misclassifications (e.g., how many *Hot* days were incorrectly predicted as *Warm*).

### Class Imbalance Handling
* Raw count confusion matrices can be misleading when classes have vastly unequal sample sizes.
* **Normalization:** Normalizing rows by the sum of each ground-truth category converts absolute counts into probabilities (rates), ensuring balanced performance evaluation across rare and frequent classes.
