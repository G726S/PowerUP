## 1. Introduction to Supervised Predictive Modelling

* **Supervised Learning Approach**: Utilises past observations containing target attributes (class labels) to analyse datasets and determine essential characteristics in the presence of a target.
* **Analogy to Human Learning**:
  * Uses observations to build a mental model of important characteristics of a phenomenon.
  * Applies generalizations to fit new data into a structured framework.
* **Algorithms**: Decision Trees, Neural Networks, Regression Modelling, etc.

## 2. Decision Trees for Classification

### 2.1 Basic Structure and Terminology
* **Structure**: A flow-chart-like tree structure representing a set of hierarchical rules (walking from the root node to a class-labelled leaf).
* **Components**:
  * **Root Node**: The starting node containing all training samples; denotes a test on an attribute.
  * **Internal Nodes**: Subsequent nodes that denote tests on attributes.
  * **Branches**: Represent outcomes of attribute tests.
  * **Leaf Nodes**: Represent final class labels or class distributions.
* **Key Property**: Attributes can be reused more than once along a single path.

### 2.2 Decision Tree Induction Process
Tree generation consists of two main phases:
1. **Tree Construction (Divide and Conquer)**: A top-down recursive process where training samples are successively partitioned according to the best separator/splitting criterion.
2. **Tree Pruning**: Identifying and removing branches that reflect noise, outliers, or overfitting.
* **Classification of Unknown Samples**: Evaluates the attribute values of an unknown sample against the decision tree paths (analogous to nested `if-then-else` statements).

### 2.3 The Basic Greedy Algorithm for Tree Construction
* **Assumptions**: Attributes are categorical (continuous-valued attributes are discretized).
* **Stopping Conditions**: Construction stops recursively when:
  1. All samples for a given node belong to the same class (pure node).
  2. There are no remaining attributes available for further partitioning.
  3. There are no samples left for the branch.

## 3. Splitting Criteria and Heuristics

To select the best attribute for splitting, heuristics are used to maximize subset homogeneity (purity) with respect to the target attribute.

### 3.1 Information Gain and Entropy
* **Entropy ($p$)**: A measure of information/uncertainty (homogeneity) in a sample:
  $$\text{Entropy}(p) = -\sum_{i=0}^{n} p_i \log_2 p_i \quad \text{for } p \in \mathbb{Q}^n$$
  * *Completely homogeneous sample (pure leaf)*: Entropy = $0$.
  * *Equally divided sample*: Maximum entropy (e.g., $1$ for binary classification).
* **Information Gain ($\text{Gain}(S, A)$)**: Measures the expected reduction in entropy achieved by partitioning dataset $S$ according to attribute $A$:
  $$\text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \text{Entropy}(S_v)$$
  * **Selection Rule**: Choose the attribute that yields the **largest Information Gain** (or lowest post-split entropy).
  * **Limitation**: Favours features with many different values (high cardinality).
* **Gain Ratio**: Solves the feature-cardinality bias of Information Gain:
  $$\text{GainRatio} = \frac{\text{Gain}}{\text{SplitInfo}} = \frac{\text{Entropy}_{\text{Before}} - \sum_{i=1}^{k} w_i \text{Entropy}_i}{-\sum_{i=1}^{k} w_i \log_2 w_i}$$

### 3.2 Gini Index
* **Gini Impurity ($p$)**: Measures the probability of a randomly chosen element being incorrectly labeled if it were randomly labeled according to the distribution of labels in the subset:
  $$\text{Gini}(p) = 1 - \sum_{i=1}^{n} p_i^2 \quad \text{for } p \in \mathbb{Q}^n$$
* **Split Criterion**:
  $$\text{GiniIndex} = \sum_{i=1}^{n} w_i \text{Gini}_i$$
  * **Selection Rule**: Choose the feature with the **lowest $\text{Gini}_{\text{index}}$**.

### 3.3 Pearson Chi-Squared Test
* Measures differences in class distributions across attributes (commonly used in algorithms like AID, THAID, and CHAID).

### 3.4 Handling Numerical Input Features
* Avoids creating a separate branch for every distinct numerical value.
* Uses **Binary Splits** (e.g., $x < 3.4$ vs $x \ge 3.4$).

## 4. Model Complexity, Bias-Variance Trade-off, and Pruning

### 4.1 Tree Depth and Complexity
* **Model Complexity**: Determined by the total number of leaves in the tree.
* **Maximal Tree**: Built until all leaves are pure or the number of cases in a node falls below a threshold. Results in a *perfect fit on training data* but suffers from *poor generalization, high variance, and overfitting*.
* **Optimal Tree**: Chosen from a sequence of trees based on validation/test performance to balance complexity and generalisation capability.

### 4.2 Bias vs. Variance in Decision Trees
* **As tree depth increases**: Bias **decreases** while variance **increases**, leading to potential overfitting.
* **Definitions**:
  * **Bias**: Simplifying assumptions made by a model to make the target function easier to approximate (*High bias = simpler model = underfitting*).
  * **Variance**: Amount by which the estimate of the target function changes when trained on different training data (*High variance = complex model = learns noise and training set quirks = overfitting*).

### 4.3 Pruning Strategies
* **Post-Pruning**: Removes overfitting *after* the tree is fully grown by replacing nodes with leaves if the sub-tree does not contribute significantly to performance.
* **Early Stopping (Pre-Pruning)**: Prevents overfitting *during* tree construction by controlling:
  * Maximum depth of the tree.
  * Minimum number of samples required to create a leaf node.
  * Minimum number of samples required to split an internal node.

## 5. Advantages and Limitations of Decision Trees

### 5.1 Advantages
1. **Interpretable**: Decision-making rules are easily explainable and visualisable.
2. **Efficient**: Reasonable training times and fast inference application.
3. **Low Pre-processing Overhead**: Data does not require normalization or scaling.
4. **Mixed Measurement Scales**: Can natively handle nominal, ordinal, and interval features.
5. **Robust**: Can handle missing values and learn non-linear, piece-wise decision boundaries.

### 5.2 Limitations
1. **Limited Relationship Handling**: Struggles with certain linear relationships (e.g., diagonal decision boundaries).
2. **Overfitting Prone**: Highly sensitive to training noise without proper pruning or ensemble methods.
3. **Instability**: Highly sensitive to small changes in training data; greedy feature selection yields local rather than global optimal solutions.
4. **Class Imbalance Sensitivity**: Biased towards majority classes.
5. **Computational Cost**: Expensive to train on massive datasets with high dimensions.

## 6. Tree Ensembles ("Wisdom of the Crowd")

Ensemble models combine predictions from multiple base estimators to improve accuracy and robustness.

### 6.1 Bagging (Bootstrap Aggregating)
* **Mechanism**: 
  1. Generates multiple training subsets via bootstrapping (sampling uniformly *with replacement* from the training set).
  2. Trains a base decision tree in parallel on each bootstrapped dataset.
  3. Combines predictions via **majority voting** (for classification) or **averaging** (for regression).
* **Out-of-Bag (OOB) Estimation**: Evaluates model performance using training instances that were excluded (left out) during the bootstrap sampling phase of specific trees.
* **Primary Example**: **Random Forest**.

#### Random Forest Classifier Mechanics:
* Builds an ensemble of decision trees using the Gini index.
* **Algorithm Steps**:
  1. Create a bootstrapped dataset.
  2. Grow a decision tree, but at each node split, restrict feature selection to a **random subset of variables**.
  3. Repeat steps 1 and 2.
* **Properties**: Highly robust against overfitting, reduces variance effectively, and handles thousands of input features without manual variable deletion.

---

### 6.2 Boosting
* **Mechanism**: Trains weak learners sequentially, where each new model is fit to the **residual errors** (residuals) of the previous model.

#### Gradient Boosting:
* Combines sequential weak learners (decision trees) to minimize a loss function.
* **Update Formula**:
  $$F_m(x) = F_{m-1}(x) + \gamma_m h_m(x)$$
  * Where $\gamma_m$ is the learning rate and $h_m(x)$ is the new tree trained on residuals at iteration $m$.
* **Stochastic Gradient Boosting**: Introduces randomness via data subsampling and random feature selection at each step.

#### XGBoost (Extreme Gradient Boosting):
* An optimized implementation of gradient boosting utilizing an additive tree model.
* Combines trees via an optimal linear combination to maximize computational efficiency and predictive accuracy in structured data competitions.
