# Supervised Learning: Regression Modelling

## 1. Introduction to Regression Analysis

Regression algorithms project the attribute space into a continuous function to predict numeric target values. 

### Commonality with Classification
* **First step:** Construct a model.
* **Second step:** Use the model to predict unknown values using regression in all its flavors (simple/multiple, linear/non-linear).

### Difference from Classification
* **Classification:** Aims at predicting categorical class labels.
* **Regression:** Aims at predicting values from continuous-valued functions.
* *(Note: Regression can be used for classification by violating key assumptions, such as in Logistic Regression or Poisson Regression).*

---

## 2. Linear Regression

Linear regression works most naturally with numeric attributes. In the simple case, it involves a target attribute $y$ and a single input attribute $x$ to fit a regression line:
$$\hat{y} = w_0 + w_1 x$$

* **$w_0$ ($y$-intercept):** The predicted value of $y$ when $x = 0$.
* **$w_1$ (slope):** The rate of change ($\frac{\Delta y}{\Delta x}$). For each change of one unit in $x$, the average change in the mean of $y$ is about $w_1$ units.
* **Coefficients:** Calculated from the training data.
* **Residuals ($\epsilon$):** Differences between observed ($y$) and predicted ($\hat{y}$) values (errors).
$$\epsilon = \hat{y} - y$$

### The Least Squares Method
The best-fitting line is found by minimizing the total error (sum of squared residuals):
$$S = \sum_{i=1}^{|D|} \epsilon_i^2$$

The estimated coefficients using the method of least squares are calculated as:
$$w_1 = \frac{\sum_{i=1}^{|D|} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{|D|} (x_i - \bar{x})^2}$$

$$w_0 = \bar{y} - w_1\bar{x}$$

### Multiple Linear Regression
Extends linear regression to handle multiple input attributes ($k$ variables):
* **2-D input data:** $y = w_0 + w_1 x_1 + w_2 x_2$
* **$k$-D input data:** $y = w_0 + w_1 x_1 + w_2 x_2 + \dots + w_k x_k$
* Solvable by extending the least squares method.

## 3. Evaluation Measures for Numeric Prediction

Common numeric prediction error metrics and performance indicators include:

* **R-squared ($R^2$):** Measures the proportion of total variance explained by the model.
  $$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$
  * *Range:* Usually between 0 and 1.
  * $R^2 = 0$: Bad model; no evidence of a linear relationship.
  * $R^2 = 1$: Good model; line perfectly fits the data.
* **Mean Absolute Error (MAE):** $\frac{1}{n} \sum_{i=1}^n |y_i - f(x_i)|$. Gives equal weight to all distances; uses the same unit as the target column.
* **Mean Squared Error (MSE):** $\frac{1}{n} \sum_{i=1}^n (y_i - f(x_i))^2$. A common loss function.
* **Root Mean Squared Error (RMSE):** $\sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - f(x_i))^2}$. Weights big differences more heavily; uses the same scale/unit as the target column.
* **Mean Signed Difference:** $\frac{1}{n} \sum_{i=1}^n (y_i - f(x_i))$. Informative only about the direction of error.
* **Mean Absolute Percentage Error (MAPEs):** $\frac{1}{n} \sum_{i=1}^n \frac{|y_i - f(x_i)|}{|y_i|}$. Requires non-zero target column values.

## 4. Linear Regression Assumptions and Limitations

### Assumptions
1. **Linearity:** A linear relationship exists between the independent and dependent variables. (Correlation is required; causation is not necessary).
2. **Independence:** Residuals (errors) are independent of each other (crucial for time-series data).
3. **Homoscedasticity:** Residuals have constant variance across all levels of $x$.
4. **Normality:** Residuals follow a normal distribution centered at 0.

### Limitations
* Cannot capture complex non-linear relationships.
* Highly sensitive to outliers.
* Prone to underfitting if the true relationship is non-linear.

---

## 5. Polynomial Regression

When data exhibits a curvilinear relationship, linear models fail. Polynomial regression extends linear regression by adding polynomial terms:
$$\hat{y} = b_0 + b_1 x + b_2 x^2 + b_3 x^3 + \dots + b_N x^N = \sum_{i=0}^{N} b_i x^i$$

### Limitations and Hyperparameters
* **Choice of Polynomial Order ($N$):** Acts as a model hyperparameter. Selected and evaluated using a validation dataset.
* **Overfitting:** Higher-order polynomials ($N$-th order) tightly fit training data (low training error) but generalize poorly to unseen validation/test data (high validation error).
* **Sensitivity to Outliers & Noise:** Highly susceptible to noise when degree $N$ is too high.

## 6. Logistic Regression (Regression for Classification)

Logistic regression is used when the target variable is categorical (e.g., binary: 0 or 1, success/failure, yes/no). It predicts the **probability** of a particular class given input features.

### Mathematical Formulation
The logistic (sigmoid) function constrains predicted probabilities to lie strictly between 0 and 1:
$$P(Y=1|X) = \pi = \frac{e^{\beta_0 + \beta_1 X}}{1 + e^{\beta_0 + \beta_1 X}} = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$$

### Logit Form (Log-Odds)
Taking the natural logarithm of the odds ratio ($\frac{\pi}{1 - \pi}$) yields a linear equation in the parameters:
$$\text{Logit}(\pi) = \ln\left(\frac{\pi}{1 - \pi}\right) = \beta_0 + \beta_1 X$$

* **Odds ratio:** $\frac{p}{1-p}$
* **Logit:** $\ln\left(\frac{p}{1-p}\right)$

### Parameter Estimation: Maximum Likelihood Estimation (MLE)
Unlike linear regression (which uses least squares), logistic regression parameters ($\beta_0, \beta_1$) are estimated using **Maximum Likelihood Estimation (MLE)**.
* **Likelihood Function ($L$):** Measures the probability of observing the sample data given parameters $\theta$:
  $$L(\theta) = P(X|\theta) = \prod_{i=1}^n p(x_i|\theta)$$
* **Log-Likelihood ($LL$):** Maximized during training:
  $$LL(\theta) = \sum_{i=1}^n \left[ y_i \log(p_i) + (1 - y_i)\log(1 - p_i) \right]$$
* **Optimization Goal:** Find $\hat{\theta} = \arg\max_\theta LL(\theta)$.

---

## 7. Comparison: Linear vs. Logistic Regression

| Feature | Linear Regression | Logistic Regression |
| :--- | :--- | :--- |
| **Target Attribute Type** | Continuous / Interval attribute | Categorical (Binary or Ordinal) attribute |
| **Input Attributes** | Any measurement level | Any measurement level |
| **Predicted Output Value** | Expected mean value of $y$ | Probability of a class membership ($\in [0, 1]$) |
| **Estimation Method** | Least Squares Method | Maximum Likelihood Estimation (MLE) |

---

## 8. Summary of Regression Models: Pros and Cons

### Pros
* Fast application and computation.
* High simplicity, interpretability, scientific acceptance, and widespread availability.
* Typically serves as the baseline/first method tested for numeric prediction problems.

### Cons
* Many real-world phenomena violate linearity assumptions.
* Struggles with high-dimensional feature spaces or missing values without preprocessing.
* Susceptible to overfitting (especially polynomial/high-order variants) and noise.

> **General Rule:** Use regression models when the dataset is relatively clean, small, and satisfies structural assumptions.
