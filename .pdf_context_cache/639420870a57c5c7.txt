# Machine Learning for Structured Data: Applications to Computer Vision

---

## 1. Introduction to Structured Data and Spatial Properties

### Structured Data Characteristics
* **Definition:** Data where elements have inherent relationships, ordering, or structural dependencies.
* **Key Feature:** Correlation between neighbors.
* **Examples of Structured Data:**
  * Images and Scans (Spatial structure, 2D/3D grids)
  * Financial Series / Time Series (Temporal structure)
  * Sound / Audio (Temporal waveforms)
  * Temperature records (Time series)
  * Communication grids

### Limitations of Flattening Structured Data (MLPs vs. CNNs)
* **MLP Limitation:** Standard multi-layer perceptrons require flattening multi-dimensional inputs into a large $1\text{D}$ vector ($n \times 1$). 
* **Loss of Spatial Order:** Flattening an image ignores spatial topology. Shuffling an image's pixels completely randomly produces the exact same histogram and yields identical results when trained via an unconstrained MLP, because order does not matter to a flat vector of independent inputs.
* **Parameter Explosion:** Fully connected layers scale poorly with high-resolution image inputs due to the massive number of spatial connections required.

## 2. Fundamentals of Computer Vision

### Common Computer Vision Tasks
1. **Image Classification / Image Recognition:**
   * **Assumption:** One object class per image.
   * **Task:** Classify the entire image, no localization (e.g., Output: `CAT`, $99\%$).
2. **Semantic Segmentation:**
   * **Assumption:** No distinct object instances; focus on every pixel.
   * **Task:** Classify every single pixel into category labels (e.g., `GRASS`, `CAT`, `TREE`, `SKY`).
3. **Object Detection:**
   * **Assumption:** Zero or more objects of interest.
   * **Task:** Classify and coarsely localize objects using bounding boxes (e.g., `DOG`, `DOG`, `CAT` with bounding box coordinates and confidence scores like $95\%$, $82\%$, $91\%$).
4. **Instance Segmentation:**
   * **Assumption:** Zero or more objects of interest.
   * **Task:** Classify and precisely localize/mask distinct object instances.
5. **Panoptic Segmentation:** Combines semantic segmentation (stuff classes like sky/road) and instance segmentation (thing classes like individual people or cars).

### Major Benchmarks in Computer Vision
* **ImageNet (ILSVRC):** Large-scale visual recognition challenge containing $1.2$ million training images and $1000$ object classes. Tracks top-$1$ accuracy across years (progressing from AlexNet to modern ResNet and SOTA meta-pseudo labels).
* **COCO (Common Objects in Context):** Evaluates dense prediction tasks such as object detection and segmentation using metrics like Box mAP.

### Major Assumptions in Computer Vision
1. **Closed-world assumption:** We know what object classes we are interested in, and we have labeled images for those exact classes.
2. **I.I.D. assumption:** The training dataset distribution matches the distribution of data encountered in real-world end applications (vulnerable to feature shift or class shift).
3. **Unambiguous ground-truth:** There is no ambiguity to the true label of an image, object, or pixel (e.g., edge cases like distinguishing a dog from a wolf, cat vs. dog, or foreground cat vs. background tree can violate this).

## 3. Convolutions vs. Linear Layers

### Matching Filters / Template Matching
* **Concept:** Instead of dense connections, spatial patterns (like a `nose` or `edge`) are detected via a sliding template filter.
* **Operation:** Position the filter over an image patch, multiply matching pixels, and sum the results. Maximum response occurs when the local pattern matches the filter (maximal signal).
* **Kernels:** Typically designed or learned such that kernel weights sum to $0$.

### Convolutional Filters and Kernels
* **Definition:** A filter must extend the full depth ($C_{in}$) of the input volume.
* **Dimensions:**
  * Input Volume: $w \times h \times C_{in}$
  * Filter/Kernel Size: $k_w \times k_h \times C_{in} \times C_{out}$
  * Bias Vector: $1 \times C_{out}$
  * Output Volume: $w' \times h' \times C_{out}$
* **Mathematical Operation:**
  $$\sum_{i,j,c} w_{i,j,c} x_{i,j,c} + b = \mathbf{W}^T \cdot \mathbf{x} + b$$

### Key Properties of Convolutions
* **Translation Invariance:** A feature detected in one part of the image will trigger the same response if shifted to another location due to weight sharing across the spatial grid.
* **Local Receptive Fields:** Neurons are only connected to a local region of the input volume, preserving spatial topology.

## 4. Convolutional Layer Hyperparameters & Output Dimensions

### Output Size Formula
Given:
* $N = \text{size of input spatial dimension (width or height)}$
* $F = \text{filter size}$
* $P = \text{padding size}$
* $S = \text{stride}$

$$\text{Output size} = \frac{N + 2P - F}{S} + 1$$

### Core Hyperparameters
* **Kernel Size ($F$):** Influences the scale of spatial features captured (e.g., $3 \times 3$, $5 \times 5$, $11 \times 11$). Deeper layers build larger **receptive fields** by compounding smaller convolutional layers.
* **Stride ($S$):** Step size by which the filter slides across the input. A stride of $2$ downsamples the spatial dimensions.
* **Zero Padding ($P$):** Adding a border of zeros around the input to control output spatial dimensions and prevent edge shrinkage.

---

## 5. Pooling Layers

* **Purpose:** Reduce the spatial dimensionality (downsampling) of activation maps while retaining salient features.
* **Types:**
  * **Max Pooling:** Takes the maximum value within the pooling window (e.g., $2 \times 2$ window). Strongly reinforces spatial invariance.
  * **Mean Pooling:** Takes the average value within the pooling window.
* **Characteristics:**
  * **No learnable parameters.**
  * Hyperparameters: Type of pooling, filter size, and stride.
  * Applied independently per activation map/channel.

## 6. Convolutional Neural Network (CNN) Architecture

### Typical Pipeline Structure
$$\text{Input Image} \rightarrow [\text{Conv} \rightarrow \text{ReLU}]^+ \rightarrow [\text{Pooling}] \rightarrow \dots \rightarrow \text{Flatten} \rightarrow \text{Linear Classifier} \rightarrow \text{Output Classes}$$

* **Early Layers:** Learn very simple low-level features (edges at various orientations, contrasting color patterns).
* **Intermediate Layers:** Combine simple features into mid-level parts (e.g., shapes, textures, parts of objects like eyes, noses).
* **Deep Layers:** Capture high-level semantic representations (complete objects, faces, complex concepts).

### Classic Architectures
* **VGG-16:** Straightforward deep stack of small $3 \times 3$ convolutions and max-pooling layers, terminating in fully connected layers (`FC-6`, `FC-7`, `FC-8`).
* **U-Net:** Designed for semantic and instance segmentation. Uses an encoder-decoder structure with **skip connections** (concatenating high-resolution encoder feature maps with upsampled decoder features) to recover fine-grained spatial localization without excessive deep-layer degradation.

## 7. Training Challenges and Regularization in Deep CNNs

### The Vanishing / Exploding Gradient Problem
* Deep networks relying on long chains of transformations suffer from instability during backpropagation due to repeated applications of the chain rule.
* Small gradients cause upstream layers to stop learning (**vanishing gradient**), while large gradients cause numerical overflow (**exploding gradient**).

### Residual Networks (ResNet) & Skip Connections
* **Solution:** Introduce residual blocks with shortcut/skip connections that bypass one or more layers:
  $$\mathcal{F}(x) + x$$
* **Benefit:** Allows gradients to flow directly back through the identity shortcut connection from later layers to earlier layers, stabilizing the training of extremely deep networks (e.g., ResNet-50, ResNet-101, ResNet-152).

### Generalization Techniques
1. **Dropout:** Randomly zeroes out a percentage of neuron activations during training to prevent co-adaptation and mitigate overfitting. Typically applied in linear/fully-connected layers (or Spatial Dropout / Dropout2D for convolutional feature maps).
2. **Data Augmentation:** Apply random transformations to training images (cropping, resizing, rotation, flipping, color jitter) to expand training distribution diversity and encourage generalization.
3. **Input Normalization:** Standardize input image channels to zero mean and unit variance:
  $$\frac{x - \mu}{\sigma}$$
  Brings input features to the same scale, preventing large parameters from dominating gradient updates.
4. **Batch Normalization Layers:** Normalize intermediate activation maps to a zero-mean, unit-gaussian distribution, then scale and shift using learnable parameters ($\gamma$ and $\beta$). 
  * *Benefits:* Speeds up training, increases robustness to poor weight initializations, acts as a regularizer, and prevents gradient blowout ($\text{NaN}$).
