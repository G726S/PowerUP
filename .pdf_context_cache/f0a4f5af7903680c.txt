# Introduction to Machine Learning

## What is Machine Learning?

- **Definition (Arthur Samuel, 1959):** A field of study that gives computers the ability to learn without being explicitly programmed.
- **Definition (Herbert Simon, 1988):** Learning is any process by which a system improves performance from experience.
- **Definition (Tom Mitchell, 1998):** A computer program is said to learn from experience $E$ with respect to some class of tasks $T$ and performance measure $P$, if its performance at tasks in $T$, as measured by $P$, improves with experience $E$.
- **Formal Task Representation:** A well-defined learning task is given by $\langle P, T, E \rangle$.

### Programming Paradigm Comparison
- **Traditional Programming:** 
  - Inputs: Data + Program
  - Process: Computer executes program on data
  - Output: Output
- **Machine Learning:** 
  - Inputs: Data + Output (Labels/Answers)
  - Process: Computer processes data and outputs to learn rules/patterns
  - Output: Program (Model)

---

## Defining the Learning Task ($\langle P, T, E \rangle$ Examples)

- **Playing Checkers:**
  - $T$: Playing checkers
  - $P$: Percentage of games won against an arbitrary opponent
  - $E$: Playing practice games against itself
- **Recognizing Hand-written Words:**
  - $T$: Recognizing hand-written words
  - $P$: Percentage of words correctly classified
  - $E$: Database of human-labeled images of handwritten words
- **Autonomous Driving:**
  - $T$: Driving on four-lane highways using vision sensors
  - $P$: Average distance travelled before a human-judged error
  - $E$: A sequence of images and steering commands recorded while observing a human driver
- **Spam Filtering:**
  - $T$: Categorize email messages as spam or legitimate
  - $P$: Percentage of email messages correctly classified
  - $E$: Database of emails, some with human-given labels

## When to Use Machine Learning

- **Use ML when:**
  - Human expertise does not exist (e.g., navigating on Mars).
  - Humans cannot easily explain their expertise (e.g., NLP, image recognition, speech recognition).
  - Models must be customized/personalized (e.g., personalized medicine, Netflix recommendations).
  - Models handle massive volumes of complex data (e.g., genomics).
- **Learning is NOT useful when:**
  - Tasks can be solved via direct analytical calculation or deterministic rules (e.g., calculating payroll, tax calculation, password authentication).

## Types of Machine Learning

### 1. Supervised Learning (Predictive Modelling)
- **Definition:** The training data (observations, measurements, features) are accompanied by target labels indicating the class or value of the observations.
- **Components:** Uses a labeled training set where each instance vector $\mathbf{x} = (x_1, x_2)$ maps to a target output $y$.
- **Key Sub-types:**
  - **Classification:** Predicts discrete categorical values or class labels (e.g., email spam vs. legitimate, disease vs. healthy, animal identification as Elephant vs. Tiger).
    - *Example formulation:* $f(\text{feature\_vector}, \text{model}) = \text{class\_label}$
  - **Regression (Value Prediction):** Predicts continuous real values (e.g., house price estimation, loan amount prediction).
    - *Example formulation:* $f(\text{feature\_vector}, \text{house\_image}) = 20500.50$

### 2. Unsupervised Learning (Clustering & Description)
- **Definition:** The class labels of the training data are unknown; the algorithm discovers hidden common patterns or intrinsic structures in unlabeled data.
- **Objectives:** Grouping data points based on similarity (closeness) or probability distribution. Data points within the same cluster are more similar to each other than to those in separate clusters.
- **Key Sub-types:**
  - **Clustering:** Partitioning unlabelled instances into subgroups (e.g., customer segmentation by age, income, and education; grouping similar documents).
  - **Dimensionality Reduction (e.g., PCA):** Reducing feature space complexity while retaining critical variance.

### 3. Semi-Supervised Learning
- **Definition:** Utilizes a training set containing both a large amount of unlabelled data and a small subset of labeled data.
- **Mechanism:** The model labels the unlabelled data by leveraging structural patterns found via modified unsupervised learning procedures.

### 4. Reinforcement Learning
- **Definition:** An agent learns to make decisions by interacting with an environment through trial and error, taking actions and receiving feedback in the form of rewards or punishments.
- **Mechanism:** Maximizes cumulative reward over time based on environmental state transitions.

## Machine Learning Pipeline / Workflow

The execution pipeline consists of sequential iterative stages:

1. **Problem Formulation:** Determine if ML is appropriate (Is there a pattern? Can it be solved analytically? Is data available?).
2. **Data Acquisition & Preprocessing:** Gather raw data (images, text, audio, structured tabular databases), clean, normalize, and visualize.
3. **Feature Engineering:** Transform raw inputs into structured feature representations or numerical matrices (e.g., using libraries like `pandas`).
4. **Establishing a Baseline:** Create a simple heuristic or baseline model for performance comparison.
5. **Model Selection & Configuration:** Choose appropriate algorithms, loss functions, and regularization techniques.
6. **Optimisation & Training:** Train models using training datasets to learn optimal parameters/weights.
7. **Hyperparameter Search:** Tune non-learned configuration settings.
8. **Evaluation & Iteration:** Assess performance on test data, analyze mistakes, and iterate back through previous pipeline steps if necessary.
9. **Deployment:** Push models into production environments to serve live predictions.

## Data Structures and Representation in ML

- **Instance / Example:** Represented as a feature vector $\mathbf{x} = [x_1, x_2, \dots, x_M]$, containing $M$ features measured for a given subject.
- **Training Set (Supervised):** Consists of $N$ instances paired with respective target labels/outcomes: 
  $$\text{Dataset} = \{(\mathbf{x}_1, y_1), (\mathbf{x}_2, y_2), \dots, (\mathbf{x}_N, y_N)\}$$
- **Training Set (Unsupervised):** Consists purely of feature vectors without target labels:
  $$\text{Dataset} = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N\}$$
- **Data Characteristics:** 
  - **Structured Data:** Can be displayed neatly in rows, columns, and relational databases (numbers, dates, strings); accounts for an estimated 20% of enterprise data.
  - **Unstructured Data:** Cannot be easily arranged in flat relational tables (images, audio, video, word processing files, emails); accounts for an estimated 80% of enterprise data.

## Related Terminologies & The Data Science Umbrella

- **Data Science:** Acts as an overarching umbrella field encompassing data engineering, analytics, and machine learning.
- **Data Analysis:** The process of examining, transforming, and arranging data to discover insights that support decision-making.
- **Data Analytics:** The tools, infrastructure, and technical stack used to perform data analysis, collection, storage, and organization.
- **Data Mining (DM):** The systematic automated process of extracting hidden, valid, and potentially useful patterns and meaningful information from large datasets.
- **Artificial Intelligence (AI):** The broad scientific capability of machines to simulate human intelligence, cognitive processing, and reasoning. *(Note: Not all AI systems use machine learning; rule-based or heuristic systems can be AI without being ML).*
- **Machine Learning (ML):** A subset of AI focused on algorithms that allow systems to learn patterns directly from data.
- **Deep Learning:** A specialized subset of ML based on multi-layered artificial neural networks with deep architectures designed to mimic human cognitive and reasoning capabilities.
- **Generative AI (GenAI):** A branch of AI/ML that generates novel synthetic content (text, images, audio, code) by learning underlying statistical probability distributions and structures from existing data.
- **Large Language Models (LLMs):** Deep learning-based models trained on massive text corpora to model word sequence probabilities, predict subsequent tokens, and generate natural language responses (e.g., GPT architectures with billions of parameters).

## Hardware Considerations: GPUs vs. CPUs

- **CPUs:** Compared to a motorcycle—quick to start, agile, optimized for sequential task execution.
- **GPUs:** Compared to an airplane—takes significant time to initialize and load data into memory, but achieves massive throughput and is super-fast once processing highly parallel matrix operations required by deep learning.
