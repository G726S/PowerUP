# Introduction: Clustering vs. Classification

- **Fundamental Goal**: Determine whether a given data point belongs to class A (blue) or class B (red) in a feature space.
- **Two Main Strategies to Find Clusters**:
  1. **Find the clusters directly** (e.g., K-Means, Gaussian Mixture Models).
  2. **Find the boundary between the clusters** (e.g., K-Nearest Neighbour, Decision Trees, Support Vector Machines, Artificial Neuronal Networks).

---

# Classic Machine Learning Models

- **K-Nearest Neighbour (KNN)**:
  - Uses all training data as exemplars.
  - Finds the $k$ closest neighbours using Euclidean distance and takes a vote.
- **Simplest Cluster Model**:
  - Represent each cluster by one point at the centre (e.g., mean).
  - Compute distances from each data point to the centres; the closest wins, dividing the search space with linear boundaries.
- **Complex Cluster Models**:
  - **Fuzzy C-Means**: Circular or hyperspherical cluster boundaries.
  - **Gaussian Mixture Model (GMM)**: Normal distributions fitting elliptical/complex shapes.
- **Decision Trees**:
  - Split the feature space using horizontal and vertical straight lines (axis-aligned splits) evaluated recursively.
- **Support Vector Machine (SVM)**:
  - Finds an arbitrary linear boundary with a defined "buffer zone" ($\Delta$) that minimises classification errors and maximises the margin.
- **Random Forests**:
  - Ensemble of many decision trees to increase robustness and prevent overfitting.

# Artificial Neural Networks (ANN): The Geometric View

## The Single Artificial Neuron
- **Linear Model**:
  - $z = ax + by + c$
  - In matrix notation: $y = w_1x_1 + w_2x_2 + b = \mathbf{W}^T\mathbf{X} + b$
  - Weight vector: $\mathbf{W} = \begin{bmatrix} w_1 \\ \vdots \\ w_D \end{bmatrix}$, Input vector: $\mathbf{X} = \begin{bmatrix} x_1 \\ \vdots \\ x_D \end{bmatrix}$, where $D$ is the input dimension.
- **Geometric Interpretation**:
  - Computing $\mathbf{W}^T\mathbf{X}$ represents a **dot product / projection** of input vector $\mathbf{X}$ onto vector $\mathbf{W}$, followed by a shift of $b$ in the direction of $\mathbf{W}$.
  - One neuron defines **one linear boundary** (a line in 2D, a 2D plane in 3D).
  - Classification rule: Class 1 if $z > 0$, Class 2 if $z < 0$.

## Activation Functions
- **Need**: Without an activation function, stacking multiple linear layers collapses into a single linear projection ($y = \mathbf{a}^T\mathbf{X}$). Activation functions introduce **non-linearity**, allowing layers to non-linearly warp space.
- **Common Activation Functions**:
  - **Unit Step (Heaviside)**: $\phi(z) = 0$ if $z < 0$; $0.5$ if $z = 0$; $1$ if $z > 0$.
  - **Sign (Signum)**: $\phi(z) = -1$ if $z < 0$; $0$ if $z = 0$; $1$ if $z > 0$.
  - **Linear**: $\phi(z) = z$.
  - **Piece-wise linear**: Used in SVMs.
  - **Logistic (Sigmoid)**: $\phi(z) = \frac{1}{1 + e^{-z}}$, squashing outputs between $(0, 1)$.
  - **Hyperbolic tangent (tanh)**: $\phi(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$, ranging from $(-1, 1)$.
  - **Rectified Linear Unit (ReLU)**: $\phi(z) = \max(0, z)$. Super fast to compute, widely used.
  - **Softplus**: $\phi(z) = \ln(1 + e^z)$.

## Multi-Class Linear Classifier
- For $m$ classes and $n$ input features:
  - Weight matrix $\mathbf{W}$ has dimensions $(n, m)$.
  - Bias vector $\mathbf{b}$ has dimensions $(m, 1)$.
  - Output score vector: $\mathbf{y} = \mathbf{W}^T\mathbf{x} + \mathbf{b}$
  - Predicted class = $\text{argmax}(\mathbf{y})$.

# Loss Functions for ANN

- **Goal**: Measure how poorly the network performs by comparing predicted outputs ($\mathbf{\hat{y}}$) against ground truth labels ($\mathbf{y}$).

## 1. Mean Squared Error (MSE) Loss (Regression)
$$L_{MSE} = \frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y}_i)^2$$
- Used primarily for regression tasks where outputs are continuous values.

## 2. Hinge Loss / Multiclass SVM Loss
$$L = \sum_{j \neq GT} \max(0, \hat{y}_j - \hat{y}_{GT} + \Delta)$$
- Penalizes incorrect class scores ($\hat{y}_j$) that fail to stay lower than the correct class score ($\hat{y}_{GT}$) by at least a margin $\Delta$.

## 3. Softmax & Cross-Entropy Loss (Classification)
- **Softmax Normalisation**: Converts raw unnormalised scores ($\mathbf{\hat{y}}$) into pseudo-probabilities:
  $$\text{Softmax}(\mathbf{\hat{y}})_i = \frac{e^{\hat{y}_i}}{\sum_{j=1}^{m} e^{\hat{y}_j}}$$
- **Cross-Entropy Loss (Softmax Loss)**: Minimizes the negative log-likelihood of the correct class:
  $$L_{CE} = -\log\left(\frac{e^{\hat{y}_{GT}}}{\sum_{j} e^{\hat{y}_j}}\right) = -\hat{y}_{GT} + \log\sum_{j} e^{\hat{y}_j}$$
  - Intuition: $-\hat{y}_{GT}$ punishes low correct-class scores, while $\log\sum_{j} e^{\hat{y}_j}$ approximates a $\max$ function over all class scores.

# Optimisation and Gradient Descent

## Standard Gradient Descent
- **Parameter Update Rule**:
  $$\mathbf{w}^{(\tau)} = \mathbf{w}^{(\tau-1)} - \eta \nabla E(\mathbf{w}^{(\tau-1)})$$
  where $\eta > 0$ is the **learning rate** (step size) and $E$ is the loss function.
- **Data Normalisation**: Essential prior to training. If input features have vastly different scales, gradients average out incorrectly, distorting the path to the minimum.

## Variants of Gradient Descent
- **Batch Gradient Descent**: Computes gradients over the entire dataset per update step. Stable but memory-intensive.
- **Stochastic Gradient Descent (SGD)**: Updates weights using only 1 randomly sampled data point per step. Computationally fast, but extremely noisy and prone to high oscillation in narrow canyons.
- **Mini-Batch Gradient Descent**: Uses small batches of data (as large as fit in memory) to balance stability and speed.
- **Momentum**: Simulates a heavy ball rolling down a canyon, dampening oscillations and accelerating along consistent gradient directions:
  $$\Delta \mathbf{w}^{(\tau-1)} = -\eta \nabla E(\mathbf{w}^{(\tau-1)}) + \mu \Delta \mathbf{w}^{(\tau-2)}$$
  where $\mu$ is the momentum parameter (combining first-order speed and second-order acceleration terms).
- **AdaGrad (Adaptive Gradient)**: Adapts individual learning rates for each parameter by scaling inversely with the square root of the running sum of historical squared gradients:
  $$r_i^{(\tau)} = r_i^{(\tau-1)} + \left(\frac{\partial E}{\partial w_i}\right)^2$$
  $$w_i^{(\tau)} = w_i^{(\tau-1)} - \frac{\eta}{\sqrt{r_i} + \delta} \left(\frac{\partial E}{\partial w_i}\right)$$
- **RMSProp**: Replaces AdaGrad’s cumulative sum with an exponentially decaying moving average of squared gradients to prevent learning rates from shrinking to zero too early.
- **Adam (Adaptive Moment Estimation)**: Combines RMSProp (moving average of squared gradients) with Momentum (moving average of gradients) alongside bias correction terms. Widely considered the default standard optimiser.

## Learning Rate Scheduling
- **Large Learning Rate**: Fast initial progress, but risks overshooting minima or causing unstable training.
- **Small Learning Rate**: Stable convergence inside steep canyons, but requires excessive iterations.
- **Schedulers (e.g., `ReduceLROnPlateau` in PyTorch)**: Dynamically lower the learning rate during training when validation metrics plateau.

# Deep Neural Networks and Backpropagation

## Universal Approximation Theorem
- A two-layer feed-forward neural network with a single hidden layer containing non-linear activation units can approximate any continuous function over a compact subset of $\mathbb{R}^D$ to arbitrary accuracy.

## Network Capacity & Architecture
- **Layer Width**: Number of neurons per layer.
- **Network Depth**: Number of hidden layers. Stacking multiple layers maps input feature spaces into progressively transformed spaces where complex decision boundaries become linearly separable.

## Backpropagation
- **Mechanism**: The method used to calculate gradients of the loss function with respect to every weight and bias in a deep network.
- **Chain Rule of Calculus**: Computes composite derivatives backward through the network layers:
  $$\frac{dg}{dx} = \frac{dg}{df} \cdot \frac{df}{dx}$$
- **Vanishing Gradients**: Occurs when activation function derivatives approach zero for extreme inputs (e.g., flat regions of sigmoid, tanh, or negative domains of ReLU), causing training to stall because updates ($\frac{\partial L}{\partial w}$) vanish.

# Preventing Overfitting

- **Overfitting**: High-capacity models memorise training data noise rather than generalising.
- **Regularization ($L_1$ and $L_2$)**:
  - Adds a penalty term based on weight magnitudes to the task loss:
    $$L = L_{task} + \alpha L_{reg}$$
  - $L_1$ Regularization ($L_{reg1} = \sum_i |w_i|$): Encourages sparse weights.
  - $L_2$ Regularization ($L_{reg2} = \sum_i w_i^2$): Penalizes large weights, smoothing decision boundaries.
- **Early Stopping**: Monitor validation loss during training and halt execution when validation error begins to rise while training loss continues to fall.
- **Dropout**: Randomly drop (zero out) a percentage of neuron connections (e.g., with probability $p=0.5$) during each training iteration to prevent complex co-adaptations. Disabled during inference (`model.eval()`).
