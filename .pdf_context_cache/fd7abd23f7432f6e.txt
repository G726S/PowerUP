# IFN580 Machine Learning: Supervised Learning Introduction

## 1. Introduction to Supervised Learning

* **Definition**: Supervised learning is a task-driven machine learning approach where a model learns to perform a specific task using pre-labeled data.
* **Core Requirements**:
  * Define a specific task for the ML model.
  * Provide data that is explicitly labeled with the correct prediction/target for that specific task.
* **Task-Driven Nature**: The model learns by using target attribute information, though algorithms vary in how they utilize this target information.
* **Human Learning vs. Machine Learning**:
  * Human learning is very data-efficient, operates as an entire multitasking system (vision, language, motor control), and takes years to develop.
  * Machine learning does not need to mimic human learning; it serves specific purposes, may borrow ideas from biological systems (e.g., neural networks), and can perform either better or worse than humans.

---

## 2. Predictive Modeling: Classification vs. Regression

Predictive modeling is split into two primary types based on the nature of the target attribute:

### Classification (Categorical Labels)
* **Task**: Find a model for the class attribute as a function of the values of other attributes to predict categorical labels.
* **Target Types**: 
  * Binary target (e.g., Event / No Event)
  * Multi-class problem (Nominal or Ordinal)
* **Examples of Class Labels**:
  * Loan eligibility: `'YES'` / `'NO'`
  * Patient treatment: `'A'`, `'B'`, or `'C'`
  * Document topic: `'sport'`, `'politics'`, `'entertainment'`
  * Product rating: `'good'`, `'average'`, `'bad'`
  * Email urgency: `'urgent'`, `'non-urgent'`
  * Transaction anomaly: `'anomalous'`, `'normal'`
  * Personality: `'introvert'`, `'extravert'`, `'both'`

### Regression / Value Prediction (Continuous Labels)
* **Task**: Find a model for a continuous target attribute as a function of the values of other attributes.
* **Target Types**: Numeric / interval (e.g., Age or Amount).
* **Examples**:
  * Approved Loan Amount ($$$$)
  * Crash rate prediction
  * House price prediction

---

## 3. The 3-Step Supervised Learning Modelling Process

1. **Model Construction / Training / Learning**:
   * Uses a **Training Set** (a set of all records used to construct the model).
   * Each instance belongs to a predefined class/value (target label).
   * Generates models represented as classification rules (IF-THEN statements), decision trees, neural networks, or regression functions.
2. **Model Evaluation / Testing**:
   * Estimates model accuracy using an independent **test** or **validation set**.
   * **Accuracy Rate**: The percentage of test set samples correctly classified by the model.
3. **Model Use**:
   * The trained and evaluated model is deployed to classify unseen instances (assign class labels or predict values).

---

## 4. Overfitting, Underfitting, Bias, and Variance

### Definitions
* **Overfitting**: A learned hypothesis fits the training data *too* well—capturing minor details, outliers, and random noise—resulting in a failure to generalize to new, unseen test data.
* **Underfitting**: A model is too simple and overlooks underlying patterns in the training data, failing to model the training data or generalize to new data.
* **Bias**: Simplifying assumptions made by a model to make the target function easier to approximate. High bias leads to underfitting.
* **Variance**: The amount by which the estimate of the target function will change given different training data. High variance leads to overfitting.

### Model Complexity and Generalization
* **Too flexible (Complex model)**: Low bias, high variance, prone to overfitting. Captures noise.
* **Not flexible enough (Simple model)**: High bias, low variance, prone to underfitting. Overlooks patterns.
* **Strategy to choose a model**: 
  1. Build a number of models on the training dataset.
  2. Select the model that performs best on the validation dataset.
  3. Use the test data to estimate generalization.

## 5. Data Distribution & Sampling Strategies

* **Purpose**: Allows mining algorithms to run on smaller datasets and enables model evaluation on independent datasets.
* **Main Dataset Splits**:
  * **Train Set**: Used to learn during the training phase.
  * **Validation Set**: Used to monitor performance during training; the model does not learn from it directly.
  * **Test Set**: Used to estimate the model's real-world performance *after* training.

### Distribution & Validation Methods
* **Batch Testing (% Distribution)**: Keeping a portion of labeled samples (e.g., 15% or 20%) strictly for testing (Train/Test split) to compare different algorithms or parameters.
* **N-Fold Cross-Validation**: 
  * Partition data into $n$ disjoint subsets.
  * Train on $n-1$ partitions and test on the remaining 1 partition.
  * Repeat across all $n$ runs and report the average of the $n$ accuracies to test robustness.

### Sampling Techniques
* **Random Sampling**: Selecting random subsets; may perform poorly if data is skewed.
* **Stratified Sampling**: Used for skewed data (e.g., fraud detection where positive classes are rare). Approximates the percentage of each class/subpopulation in the overall dataset to ensure balanced representation across splits.

## 6. Classical Supervised ML Approaches to Classification

### 1. Decision Trees
* **Structure**: Tree-like flowchart where internal nodes represent feature tests, branches represent outcomes, and leaf nodes represent class labels/risks.
* **Characteristics**: Provides piecewise constant approximation of decision regions using symbolic IF-THEN rules. Can model both linear and non-linear decision boundaries.

### 2. Nearest Neighbor (kNN)
* **Mechanism**: Does not build a global model upfront. Computes proximity (distance) between a query point and training data points, choosing the nearest neighbors to decide the outcome.
* **Characteristics**: Learns localized decision regions; sensitive to data errors/noise. Highly effective across diverse domains despite being introduced in the 1950s.

### 3. Logistic Regression & Linear Classifiers
* **Mechanism**: Finds the "best" linear function/boundary ($w_0 + w_1 x + w_2 y \geq 0$) to separate classes by minimizing squared errors.
* **Characteristics**: Often limited by being insufficiently flexible for complex non-linear data distributions.

### 4. Neural Networks
* **Mechanism**: Uses a network of parameters (such as weight matrices) to model complex decision boundaries.
* **Characteristics**: Highly flexible, capable of learning non-linear, complex regions and achieving high accuracy, but carries a high risk of overfitting to noise if unconstrained.

## 7. Evaluation Measures & Performance Metrics

### Regression Metrics
* **Error**: $\text{Error} = \|\text{true} - \text{predicted}\|$
* **Mean Absolute Error (MAE)**: 
  $$\text{MAE} = \frac{1}{n} \sum \|\text{true} - \text{predicted}\| = \frac{1}{n} \sum \text{Error}$$
* *Other metrics*: Mean Squared Error (MSE), Root Mean Square Error (RMSE).

### Classification Metrics & Confusion Matrix
A confusion matrix visualizes counts for actual vs. predicted classes (True Positives, False Positives, True Negatives, False Negatives):

| | Predicted: Yes | Predicted: No |
|---|---|---|
| **Actual: Yes** | TP (True Positive) | FN (False Negative) |
| **Actual: No** | FP (False Positive) | TN (True Negative) |

* **Accuracy**: Proportion of correct predictions out of total instances ($n$).
  $$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} = \frac{\text{correct}}{\text{correct} + \text{incorrect}}$$
* **Precision**: Proportion of positive predictions made by the model that are actually correct.
  $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
* **Recall (Sensitivity / True Positive Rate - TPR)**: Proportion of actual positive observations correctly predicted.
  $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
* **Specificity (True Negative Rate)**: Proportion of actual negative observations correctly predicted.
  $$\text{Specificity} = \frac{\text{TN}}{\text{FP} + \text{TN}} = 1 - \text{FPR}$$
* **False Positive Rate (FPR)**: 
  $$\text{FPR} = \frac{\text{FP}}{\text{TN} + \text{FP}}$$
* **F1-Score (F-Measure)**: The harmonic mean of precision and recall.
  $$\text{F1} = \frac{2 \times \text{recall} \times \text{precision}}{\text{recall} + \text{precision}}$$
* **ROC Curves and AUC (Area Under the ROC Curve)**:
  * Plots True Positive Rate (TPR) against False Positive Rate (FPR) at various threshold settings.
  * **AUC** measures how well predictions are ranked. An AUC of $0.5$ represents random guessing (diagonal line), while an AUC of $1.0$ represents perfect predictive accuracy.

## 8. Comparing Classification Algorithms

When selecting or comparing algorithms, models are evaluated across five key criteria:
1. **Model Goodness**: Predictive accuracy, RMSE, and AUC.
2. **Speed**: Computational cost involved in generating (training) and using (predicting) the model.
3. **Robustness**: Ability of the model to make correct predictions in the presence of noise and data errors.
4. **Scalability**: Ability to construct the model efficiently with large volumes of data.
5. **Interpretability**: The level of human understanding and insight provided by the resulting model structure.
